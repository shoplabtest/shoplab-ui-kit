# @shoplab/ui-kit

Shared React components and helpers for the ShopLab frontends.

Exports: `Money`, `PriceTag`, `FormField`, `Toast`, `formatMoney(amount, currency, locale?)`, `CURRENCIES`, `ApiError`, `theme`.
Amounts are integers in minor units (cents).

`npm run build` emits `dist/`; `npm test` renders components server-side.
